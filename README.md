# Sonic Colors Android - starter project

Este proyecto es un prototipo de interfaz Android con estética azul y selector local de archivos `.nds`.

IMPORTANTE:
- Este prototipo NO incluye un motor de emulación y todavía NO ejecuta ROMs.
- No incluye ROM, BIOS ni recursos comerciales.
- Para convertirlo en una aplicación jugable hay que integrar un motor de Nintendo DS compatible, respetar su licencia y conectar los controles a su API real.
- Requiere Android Studio con soporte para Kotlin y Jetpack Compose. Si la versión de Gradle/SDK no coincide con tu instalación, abre el proyecto en Android Studio y deja que sugiera las actualizaciones compatibles.

## Abrir
1. Descomprime el ZIP.
2. Abre la carpeta `SonicColorsAndroidStarter` en Android Studio.
3. Espera la sincronización de Gradle.
4. Ejecuta la app en tu TCL 50 SE o en un emulador Android.
